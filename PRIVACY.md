# Privacy Policy / 隐私政策

Last updated: September 4, 2026

## English

### Overview

YCloud WebSocket Debugger is a developer tool that captures, displays, filters, exports, and locally simulates WebSocket activity when the user explicitly opens the debugger.

### Data accessed

To provide these features, the extension may access WebSocket connection metadata, including URLs, domains, tab identifiers, connection types, connection status, and timestamps. It may also access WebSocket message payloads, which can contain website content or personal communications depending on the website being debugged.

### How data is used

The accessed data is used only to provide the extension's user-facing debugging features. The extension does not use the data for advertising, profiling, credit decisions, or any purpose unrelated to WebSocket debugging.

### Storage and transmission

Captured connections, messages, and user preferences are stored locally in the user's browser. The extension does not transmit this data to the developer or to third-party servers, and it does not sell or share user data.

Users can clear captured messages from the debugger. Removing the extension or clearing its browser storage removes locally stored extension data.

### Permissions

The `debugger` permission is used to connect to eligible browser debugging targets and inspect WebSocket traffic. The `tabs` permission is used to associate connections with their owning tabs and domains.

### Remote code

The extension does not load or execute remotely hosted code.

### Changes

This policy may be updated when the extension's data practices or functionality change. The latest version will be published at the privacy policy URL shown in the Microsoft Edge Add-ons listing.

## 简体中文

### 概述

YCloud WebSocket 调试器是一款开发者工具。仅当用户主动打开调试器时，扩展才会捕获、展示、筛选、导出和在本地模拟 WebSocket 活动。

### 访问的数据

为提供上述功能，扩展可能访问 WebSocket 连接元数据，包括 URL、域名、标签页标识、连接类型、连接状态和时间戳。扩展还可能访问 WebSocket 消息内容；根据被调试网站的不同，这些内容可能包含网站内容或个人通信。

### 数据用途

访问的数据仅用于提供扩展面向用户的 WebSocket 调试功能。扩展不会将数据用于广告、用户画像、信用决策或任何与 WebSocket 调试无关的用途。

### 存储与传输

捕获的连接、消息和用户偏好仅保存在用户浏览器本地。扩展不会将这些数据传输给开发者或第三方服务器，也不会出售或共享用户数据。

用户可以在调试器中清除已捕获的消息。移除扩展或清除其浏览器存储后，本地保存的扩展数据也会被删除。

### 权限

`debugger` 权限用于连接可调试的浏览器目标并检查 WebSocket 流量。`tabs` 权限用于将连接与所属标签页和域名关联。

### 远程代码

扩展不会加载或执行远程托管的代码。

### 变更

当扩展的数据处理方式或功能发生变化时，本政策可能更新。最新版本将发布在 Microsoft Edge 加载项商店详情页所示的隐私政策链接中。
